# 🎓 Project 08 — Security Awareness Kit

## What is this?
A set of professional security awareness materials a company could actually use — phishing guide, password policy, and incident response checklist — all written for non-technical staff.

## Why employers love this
Being able to explain security to non-technical people is a rare and valued skill. This shows communication ability, depth of knowledge, and professionalism — relevant for both SOC and GRC roles.

## Materials

### 01 — How to Spot a Phishing Email
- Urgent language — "Your account will be closed!"
- Sender address doesn't match the company
- Hovering over links shows different URL
- Unexpected attachments
- Poor spelling and grammar
- Requests for passwords or payment

### 02 — Password Security Policy (Plain English)
- Use 12+ characters
- Use a passphrase: "Coffee!Laptop#Monday" is stronger than "P@ssw0rd"
- Never reuse passwords across sites
- Use a password manager (Bitwarden is free)
- Always enable 2-factor authentication

### 03 — I Think I've Been Hacked — What to Do NOW
1. Do NOT turn off your computer (preserves evidence)
2. Disconnect from the internet (unplug network cable or turn off WiFi)
3. Call your IT security team immediately
4. Do NOT try to fix it yourself
5. Write down everything you noticed and when

### 04 — Social Engineering Awareness
- Pretexting: attacker pretends to be someone else
- Baiting: free USB stick left in car park
- Tailgating: following someone through a secure door
- Rule: If something feels wrong, it probably is — always verify
